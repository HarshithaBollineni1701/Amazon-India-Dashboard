# Amazon India – AI-Powered Sales Analytics Dashboard

## Project Overview

The **Amazon India AI-Powered Sales Analytics Dashboard** is an interactive business intelligence application designed to transform raw sales data into meaningful insights through data analytics, visualization, and Generative AI.

The project analyzes Amazon India sales data to provide a comprehensive view of business performance, including sales trends, profitability, product performance, order distribution, payment methods, fulfillment patterns, and geographical sales distribution.

Developed using Python, Pandas, Streamlit, and Plotly, the application processes and organizes sales information into key performance indicators (KPIs), interactive charts, and analytical summaries.

To extend traditional data analysis with Generative AI, the project incorporates an AI Copilot powered by Large Language Models (LLMs) and Retrieval-Augmented Generation (RAG). It enables users to ask business-related questions in natural language, retrieve relevant information from the sales knowledge base, and receive context-based analytical responses and recommendations.

The primary focus is to combine data-driven analysis with AI-assisted insights, making business information easier to explore, understand, and use for decision-making.

## Key Features

### 1. Sales Performance Analysis
- Analyze overall sales and profit performance.
- Track monthly sales trends.
- Monitor key business performance indicators.
- Explore sales performance using interactive filters.

### 2. Product and Category Analysis
- Identify top-performing products.
- Compare category-wise sales performance.
- Understand product contribution to overall sales.

### 3. Order and Fulfillment Analysis
- Examine order status distribution.
- Analyze fulfillment patterns.
- Understand order processing and delivery-related performance.

### 4. Payment and Geographical Analysis
- Explore payment method distribution.
- Analyze state-wise sales performance.
- Identify geographical sales patterns.

### 5. AI-Powered Copilot
- Interact with sales information using natural-language questions.
- Retrieve relevant business information based on user queries.
- Generate AI-assisted analytical responses.
- Provide business insights and recommendations using retrieved context.

## Technology Stack

| Technology | Application |

## Project Objective

The objective of this project is to demonstrate how data analytics and Generative AI can work together to improve business intelligence.

By combining structured sales analysis, interactive visualizations, LLM integration, and retrieval-based question answering, the application provides an accessible way to explore business data and generate meaningful insights for decision-making.
